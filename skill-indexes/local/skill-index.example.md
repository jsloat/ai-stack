# Skill Index Example

This file is the standard example artifact for a local skill index.

It establishes the example filename convention `skill-index.example.md` without finalizing the full runtime parsing contract.

Possible future contents might include:

- references to globally available skills
- references to private local-only skills
- short notes on when a skill should be used

If future tooling looks for a conventional local index file, that convention should be defined in a feature doc before implementation relies on it.
